# DT Parser v4.6.3 — Russian AI Lab UI

## Что изменилось

Только пользовательский интерфейс DT AI Lab:

- Hidden Gem → **Скрытая находка**
- Emerging → **Набирает обороты**
- Hot Product → **Горячий товар**
- Spark → **Первичный сигнал**
- Saturated → **Перенасыщен**
- Watch → **Наблюдение**
- Rising → **Рост**
- Confirmed / Rejected → **Подтверждён / Не подтвердился**
- Opportunity / Saturation / Demand / Supply / Repeatability и другие метрики карточки также переведены.

Внутренние значения базы данных и AI-модели не переименовывались. Алгоритм, пороги, +1/+3/+6, badge-уведомления и idle Chromium из v4.6.2 остаются без изменений.

Новых Railway Variables и миграций PostgreSQL нет.
