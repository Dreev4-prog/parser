DT Vinted Local Session Helper

Установка один раз:
1. Открой Chrome -> chrome://extensions
2. Включи "Режим разработчика"
3. Нажми "Загрузить распакованное расширение"
4. Выбери эту папку vinted_local_helper

Дальше:
Telegram -> Админ-панель -> Vinted Lab -> Vinted Session -> Открыть вход.
Нажми "Открыть Vinted в моём Chrome" и войди в свой аккаунт как обычно.
После подтверждения аккаунта сессия автоматически отправится в твой DT Vinted Session Worker.

Helper не сохраняет cookies локально и не читает пароль/2FA.
