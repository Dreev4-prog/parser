# DT Parser v4.23.1 — Vinted Radar 1.0 Full Market + Live Page Progress

## Что изменено

- Vinted Radar больше не просит выбирать категории вручную.
- Каждый Radar-круг получает полный live-каталог Vinted и сканирует только конечные категории (leaf catalogs), чтобы родитель и дочерние разделы не дублировали рынок.
- Для каждой категории одинаковая первичная глубина: **15 страниц**.
- В Radar-режиме скрытые recovery-страницы отключены: категория не получает 16/17/18 страницу только из-за overlap пагинации. Это сохраняет одинаковую глубину между категориями.
- Порядок категорий циклически сдвигается каждый новый круг, поэтому одна и та же категория не остаётся постоянно первой или последней.
- Если live category tree выглядит неполным, Radar не запускает «частичный весь рынок». Уже подтверждённый полный список сохраняется как fallback между кругами.

## Прогресс прохода

Экран Vinted Radar и экран конкретного прохода теперь показывают:

- общий процент круга;
- категории completed / total;
- сколько категорий прямо сейчас в работе и сколько в очереди;
- **реально пройденное число страниц**;
- основной page budget `X / (15 × categories)`;
- количество уникальных объявлений;
- текущую категорию и страницу каждого активного Vinted Scan Worker;
- последние завершённые / проблемные категории.

При ручном первом запуске экран обновляется автоматически через существующий watcher. Для автоматических следующих кругов в Radar есть кнопка **«🟣 Смотреть проход страниц»** — она открывает live-экран и включает автообновление.

## Что не менялось

- Like Momentum / Vinted Score 100.
- Live window 24 часа.
- Learning history 7 дней.
- Ручной Vinted Parser и его выбор категорий.
- Kleinanzeigen Parser / Radar / Page / Date / View workers.
- Vinted Session и Local Helper.

## Retention / защита PostgreSQL

Full-market snapshots заметно крупнее тестовых ручных сканов, поэтому Radar теперь сам очищает старые **Radar-only** проходы за пределами `7 дней learning + 1 день safety`. Ручные Vinted Parser-сканы этим cleanup не затрагиваются.
