# DT PARSER v4.0.3 — Recent Date Stream Fix

## Что исправлено

Для трёх самых частых дат — сегодня, вчера и позавчера — отдельный date-locator отключён.

Алгоритм теперь такой:

1. Начать с page 1 nationwide-выдачи.
2. Пропускать страницы, которые новее выбранной даты.
3. Как только появляются объявления выбранной даты — собирать их.
4. Продолжать, пока не набрана выбранная глубина 25/50/100 страниц либо выдача не стала старше выбранной даты.
5. Если выбранная дата продолжается за публичным окном — только тогда используется deep/regional fallback.

Страницы с частично скрытыми timestamp не останавливают свежий последовательный проход. Реальные invalid/challenge страницы по-прежнему считаются ошибкой и восстанавливаются сервером.
