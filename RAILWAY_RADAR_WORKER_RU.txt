DT Parser 4.23.23 — полная статистика DT Radar 3.0 сразу

1. Загрузите файлы патча в GitHub.
2. Сначала добавьте в основной parser: RADAR_DEDICATED_WORKER=1
3. Дождитесь перезапуска parser и строки:
   Dedicated Radar Worker mode: parser serves Telegram UI only
4. Затем создайте ОДИН новый сервис из того же GitHub-репозитория.
5. Назовите сервис "Radar Worker".
6. Start Command оставьте таким же: python service_launcher.py
7. Добавьте переменную: DT_SERVICE_ROLE=radar-worker
8. Подключите к сервису те же ссылки DATABASE_URL и REDIS_URL.
9. Добавьте BOT_TOKEN; ADMIN_IDS можно скопировать для уведомлений.
10. Оставьте ровно 1 replica.
11. Дождитесь в логах:
   role=radar-worker target=radar_worker.py
   Dedicated DT Radar Worker online
   Radar Worker deep analytics published

Даже до создания отдельного Radar Worker основной parser до запуска Telegram
создаёт полный снимок. Поэтому при входе в DT Radar 3.0 сразу видны:
воронка Radar, Candidate/Early/Strong/HOT, категории с живым спросом,
контрольные замеры, baseline за 24ч и Fast Sold.

После создания Radar Worker он делает сканирование и сохраняет полную статистику.
Live-прогресс AutoScan открывается отдельной кнопкой и не заменяет основной экран.

Важно: RADAR_WORKER_PROCESS вручную добавлять не нужно. Его автоматически ставит
service_launcher.py только внутри сервиса Radar Worker. На основном parser нужна
только переменная RADAR_DEDICATED_WORKER=1.
