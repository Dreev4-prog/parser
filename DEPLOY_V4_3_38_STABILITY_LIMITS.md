# v4.3.38 — STABILITY LIMITS

Профиль рассчитан на поток из четырёх одновременных пользователей без изменения точного parser/date/view ядра.

Изменения продукта:
- максимум 2 категории на один новый скан;
- дата — только последние 5 календарных дат: сегодня + 4 предыдущих дня;
- ручной ввод даты убран из интерфейса и запрещён для новых запусков;
- старые callback-кнопки «Ввести дату» безопасно возвращают пользователя к новому 5-дневному picker;
- 15/25/50 страниц без изменений;
- Date/Page/View Worker остаются по 4 Railway replicas;
- новых Railway Variables не требуется.

Зачем: один пользователь больше не может занять worker fleet четырьмя-пятью тяжёлыми категориями, а самое дорогое историческое окно сокращено. Это уменьшает длину очередей и время, в течение которого один scan_id удерживает Date/Page/View capacity.
