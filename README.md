# Kleinanzeigen Parser Bot v2.6.2

## Что нового

### Живой пользовательский прогресс

Внутренняя очередь, воркеры, кэш и объединение одинаковых сканов продолжают работать, но больше не показываются обычному пользователю.

После нажатия **Начать парсинг** пользователь видит одно автоматически обновляемое сообщение:

- подготовку запуска;
- количество выбранных категорий;
- общий прогресс в процентах;
- сколько категорий уже готово;
- текущую категорию;
- текущую страницу;
- сколько объявлений просмотрено;
- сколько новых найдено;
- прошедшее время;
- примерное оставшееся время.

После завершения бот автоматически формирует и отправляет файл по текущему режиму/фильтрам.

### Что скрыто внутри

- до `MAX_CONCURRENT_JOBS` пользовательских задач одновременно;
- общая внутренняя очередь;
- `CATEGORY_CACHE_TTL_SECONDS` — повторное использование свежих категорий;
- объединение одновременных запросов одной категории в один сетевой скан;
- Fast Incremental из v2.5;
- SQLite WAL для тестового многопользовательского режима.

Пользователю эти технические детали не показываются.

## Railway

Start Command:

```bash
python bot.py
```

Обязательные переменные:

```env
BOT_TOKEN=...
ADMIN_IDS=123456789
```

Дополнительные переменные можно оставить по умолчанию:

```env
MAX_CONCURRENT_JOBS=3
MAX_QUEUE_SIZE=200
CATEGORY_CACHE_TTL_SECONDS=300
STATUS_UPDATE_INTERVAL_SECONDS=1.5
```

До перехода на PostgreSQL очередь остаётся в памяти процесса, а SQLite на Railway может потеряться после redeploy/restart.
