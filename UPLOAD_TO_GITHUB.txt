DT Parser 4.23.15 — облегчённый комплект для GitHub/Railway

Это полный рабочий комплект для запуска проекта.
Удалены только тесты, архивная документация, отчёты проверок и дубликат изображения.
Рабочий Python-код и конфигурации Railway не изменены.

Как загрузить через сайт GitHub:
1. Распакуйте ZIP на компьютере.
2. Откройте репозиторий GitHub и нажмите Add file -> Upload files.
3. Откройте распакованную папку и перетащите в окно GitHub ВСЁ её содержимое,
   а не сам ZIP-файл и не внешнюю папку.
4. Нажмите Commit changes.

После коммита Railway сможет автоматически начать новый деплой.
