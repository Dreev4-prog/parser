DT Parser 4.23.16 — маленький патч поверх версии 4.23.15

1. Распакуйте ZIP.
2. В GitHub откройте Add file -> Upload files.
3. Перетащите всё содержимое этой папки в корень репозитория.
4. Подтвердите Replace для существующих файлов и нажмите Commit changes.
5. Не удаляйте остальные файлы репозитория.

После коммита Railway должен автоматически передеплоить Parser / Bot.
Ожидаемая строка запуска: version=4.23.16 target=bot.py

Изменение политики Radar:
- AutoScan остаётся единственным источником общих baseline и не получает нового лимита.
- Пользовательские сканы продолжают работать, но не добавляют baseline в общий Radar.
- Существующие наблюдения и история Radar не удаляются.
