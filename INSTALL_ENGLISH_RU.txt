DT Parser 4.23.28 — удобный английский интерфейс

Установка поверх 4.23.27:

1. Распакуйте ZIP и загрузите его файлы в GitHub с заменой.
   Папки assets/, scripts/ и tests/ должны сохранить свои имена.
2. Дождитесь завершения деплоя 4.23.28 на Railway.
3. В боте откройте /language → English. Проверьте главное меню, DT Radar,
   настройки и новую XLSX-выгрузку.
4. В /admin → Автопосты откройте каждый из двух постов и нажмите
   «🇬🇧 Предпросмотр EN». Сообщение придёт только вам.

Три новые картинки должны находиться именно здесь:
assets/dt_parser_menu_en.png
assets/promo_parser_alf_en.png
assets/promo_radar_alf_en.png

Исправлены фразы меню, первого запуска, сканов, Radar, подписки,
реферальной программы и фоновых уведомлений. Переведены разделы,
категории и заголовки XLSX/CSV. Названия товаров, поисковые запросы,
ключевые слова и URL сохраняются. В цене принимаются up to 100,
from 500, from 120 to 250. Картинки выбираются по языку пользователя.

Автопосты:

У двух стандартных постов английские тексты и картинки добавляются
автоматически. Время и состояние постов при обновлении сохраняются.
Расписание по умолчанию: Parser 12:00 МСК, Radar 17:00 МСК,
отдельный Daily Radar 20:00 МСК. Посты по-прежнему отправляются всем.

Для своих постов добавляйте «🇬🇧 EN-текст» и при необходимости
«🇬🇧 EN-картинку». Эти версии редактируются отдельно от русских.
Произвольный новый текст администратора автоматически не переводится:
если EN-текст не добавлен, используется основной текст. Без EN-картинки
используется основная. Статус готовности виден в карточке поста.

В PostgreSQL автоматически добавляются только два текстовых поля
caption_en и photo_en таблицы promo_posts. Данные и расписание сохраняются.
Новые Railway Variables, зависимости и воркеры не требуются.

Проверка выполнена локально. Патч не загружался в GitHub или Railway
автоматически. После вашего деплоя используйте шаги 3–4 для проверки
на действующем боте. Уже отправленные сообщения и старые XLSX-файлы
не меняются; откройте меню заново и сформируйте новую выгрузку.
