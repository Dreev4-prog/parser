DT Parser 4.23.27 — автопосты с Альфом для всех пользователей

Установка поверх 4.23.25 или 4.23.26:

1. Распакуйте ZIP.
2. Загрузите файлы в GitHub с заменой, сохранив структуру папок.
   Важно: две картинки должны попасть в assets/:
   assets/promo_parser_alf.png
   assets/promo_radar_alf.png
3. Дождитесь деплоя 4.23.27 на Railway.
4. Откройте /admin → ⏰ Автопосты.
5. Откройте оба поста и нажмите «👁 Предпросмотр» — сообщение придёт только вам.

Готовое расписание (ежедневно, Москва):

12:00 — DT Parser с первой картинкой, текстом и кнопками.
17:00 — DT Radar с второй картинкой, текстом и кнопками.
20:00 — существующий Daily Radar, сохранён отдельно по вашему выбору.

Два готовых поста изначально включены и идут всем зарегистрированным пользователям,
включая подписчиков и администраторов. Кнопки отключения промопостов больше нет.
Старые настройки «не присылать» не учитываются. Пропускаются только пользователи,
заблокированные администратором, и чаты, в которые Telegram не разрешает отправку.
При обновлении с 4.23.26 тексты, фото, время и состояние постов сохраняются.

В «⏰ Автопосты» доступны:

- добавить новый текстовый пост или фото с подписью;
- изменить название, текст, картинку, время и кнопки;
- включить/выключить отдельный пост;
- удалить пост после подтверждения;
- приостановить все новые автопосты;
- посмотреть результат последней отправки.

Новый пользовательский пост сохраняется выключенным. Сначала посмотрите его,
затем включите. Подпись — до 1024 символов; эмодзи иногда занимают два символа.
Картинку отправляйте как одну фотографию, без альбома.

Расписание и изменения сохраняются в PostgreSQL и переживают деплой. Если
сегодняшнее время уже прошло к моменту установки или изменения, пост начнёт
отправляться со следующего дня. Повторно за один московский день он не уйдёт.
При обрыве связи один неподтверждённый получатель может быть пропущен, чтобы
не послать ему дубликат.

Новые таблицы создаются автоматически. Новые Railway Variables, воркеры,
ручные SQL-команды и очистка базы не требуются.
