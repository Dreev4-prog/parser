# Установка патча 4.23.17

1. Распакуйте ZIP.
2. Загрузите файлы в корень GitHub-репозитория с сохранением папок и подтвердите
   замену существующих файлов.
3. Дождитесь автоматического деплоя основного сервиса `parser` в Railway.
4. Дополнительные переменные Railway и ручные SQL-команды не требуются.

Через 45 секунд после запуска появится планировщик очистки. Когда есть старые
строки, в логах `parser` будет сообщение:

```text
PostgreSQL retention batch removed=... details=...
```

Накопившийся хвост удаляется постепенно, небольшими пакетами каждые пять минут,
поэтому первый полный проход может занять несколько часов. Это не блокирует сканы.

Railway может не сразу показать уменьшение занятого тома: обычный PostgreSQL
повторно использует освобождённые страницы. Главное — после очистки объём перестаёт
расти прежними темпами. `VACUUM FULL` для работы патча не требуется.

Патч сохраняет:

- все сохранённые пользовательские сканы и их отдельную историю замеров;
- объявления, связанные с Radar, Fast Sold и сохранёнными сканами;
- реестр `listing_integrity`;
- актуальные данные Radar и кэш последних суток.
